# T01. 자기소개 페이지

[실행 사이트](https://eldi96.github.io/T01_portfolio/)

개인의 문제 해결 방식과 작업 원칙을 소개하는 정적 웹페이지입니다. 경험을 **상황·행동·결과**로 정리하고, 공개할 정보와 공개하지 않을 정보를 구분해 보여줍니다.

> 이 저장소는 현재 GitHub에 올라온 T01 페이지의 구현을 기록합니다. 별도로 구상 중인 통합 프로젝트 허브와는 다른 프로젝트입니다.

## 주요 구성

- **Intro** — 페이지 목적과 자기소개
- **Scope** — 공개 정보와 비공개 정보의 구분
- **Records** — 계획 수립, PC 조립, 함께 공부한 경험을 담은 3개 기록
- **Principles** — 계획·해결·전달이라는 세 가지 원칙
- **Contact** — 연락 방법

## 사용 기술

HTML, CSS, JavaScript로 작성했으며 별도의 빌드 도구 없이 실행할 수 있습니다.

스크롤에 따른 요소 등장 효과와 섹션 표시에는 `IntersectionObserver`를 사용하고, 기록 영역은 버튼과 방향키로 전환할 수 있도록 구성했습니다.

## 실행 방법

1. 저장소를 내려받거나 복제합니다.
2. 프로젝트 루트의 `index.html`을 브라우저에서 엽니다.
3. 페이지를 스크롤하거나 우측 점 메뉴를 이용해 섹션을 이동합니다.

## 공개 범위와 참고 사항

이 페이지는 로그인 없이 열람하는 자기소개용 정적 페이지입니다. 현재 HTML에는 검색 엔진 색인 제외를 요청하는 `noindex, nofollow` 메타 태그가 있습니다. 이 설정은 접근 통제나 비공개 보안 기능이 아닙니다.

일부 경험의 '근거' 링크는 실제 자료로 연결되지 않는 자리표시자입니다. 검증 가능한 자료를 공개하기 전까지 링크가 작동하는 것처럼 안내하지 않습니다.
